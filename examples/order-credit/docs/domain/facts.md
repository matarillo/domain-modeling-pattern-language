# 業務上の事実

事実の名前とコンテキストへの割り当ては、AI の案である（Q-20）。

## 事実の一覧

| 事実 | コンテキスト | 運ぶ情報 | 意味 | 合意状態 | 出所 |
| --- | --- | --- | --- | --- | --- |
| 注文が下書きとして保存された | 受注 | 注文、取引先、保存した日時 | 受注担当者が、入力の途中で注文を保存した | 仮説 | 要求資料 §4 手順 2 |
| 注文が提出された | 受注 | 注文、取引先、注文の金額、提出した日時 | 受注担当者が、入力を終えた注文を提出した | 仮説 | 要求資料 §4 手順 3 |
| 与信の審査が依頼された | 与信 | 注文、依頼した日時 | 自動で決まらない注文が、与信担当者の審査に回った | 要確認（Q-08） | 要求資料 §5 |
| 与信が承認された | 与信 | 注文、承認の種別（自動／審査）、判定した日時 | 注文が、与信の面から受けてよいと判定された | 仮説 | 要求資料 §4 手順 4、5 |
| 与信が断られた | 与信 | 注文、断った理由（取引停止中／審査で断った）、判定した日時 | 注文が、与信の面から受けられないと判定された | 仮説 | 要求資料 §4 手順 4、§5 |
| 与信の判定が失効した | 与信 | 注文、判定した日時、失効した日時 | 承認された判定が、7 日のうちに注文が確定しないまま有効期間を過ぎた | 要確認（Q-09） | 要求資料 §5 |
| 在庫が引き当てられた | 在庫 | 注文、引き当てた明細、引き当てた日時 | 注文の明細に、在庫が割り当てられた | 仮説 | 要求資料 §4 手順 5 |
| 在庫が引き当てられなかった | 在庫 | 注文、足りなかった明細、日時 | 在庫が足りず、引当ができなかった | 要確認（Q-01） | 要求資料 §8 |
| 注文が確定した | 受注 | 注文、確定した日時 | 与信が承認され、在庫が引き当てられた注文が確定した | 仮説 | 要求資料 §4 手順 6 |
| 出荷が指示された | 出荷 | 注文、指示した日時 | 確定した注文について、倉庫に出荷が指示された | 仮説 | 要求資料 §4 手順 7 |
| 出荷が始まった | 出荷 | 注文、始めた日時 | 倉庫担当者が、出荷を始めた（取消の境目。Q-12） | 要確認（Q-12） | 要求資料 §4 手順 7、§6 |
| 出荷が完了した | 出荷 | 注文、完了した日時 | 倉庫担当者が出荷を終え、完了が記録された | 仮説 | 要求資料 §4 手順 7 |
| 注文が取り消された | 受注 | 注文、取り消した日時 | 出荷が始まる前に、注文が取り消された | 仮説 | 要求資料 §6 |
| 在庫の引当が解除された | 在庫 | 元の引当（在庫が引き当てられた）、解除した日時 | 取り消された注文の引当が外れた | 仮説 | 要求資料 §6 |
| 与信の額が戻された | 与信 | 注文、戻した額、戻した日時 | 取り消された注文が使っていた与信の額が戻った（何を戻すかは Q-05） | 要確認（Q-05） | 要求資料 §6 |

## 事実の流れ

| 流れ | 事実の並び | 合意状態 | 出所 |
| --- | --- | --- | --- |
| 自動で承認され、出荷まで進む | 注文が提出された → 与信が承認された（自動）→ 在庫が引き当てられた → 注文が確定した → 出荷が指示された → 出荷が始まった → 出荷が完了した | 仮説 | 要求資料 §4 |
| 審査を経て承認される | 注文が提出された → 与信の審査が依頼された → 与信が承認された（審査）→ 在庫が引き当てられた → 注文が確定した → （以降は、上の流れと同じ） | 要確認（Q-06、Q-08） | 要求資料 §4、§5 |
| 与信で断られる | 注文が提出された → 与信が断られた（取引停止中、または審査で断った）。審査の場合は、間に「与信の審査が依頼された」が入る | 仮説 | 要求資料 §4、§5 |
| 在庫が足りない | 注文が提出された → 与信が承認された → 在庫が引き当てられなかった → （以降は決まっていない） | 要確認（Q-01） | 要求資料 §8 |
| 判定が失効する | 与信が承認された → （7 日のうちに注文が確定しない）→ 与信の判定が失効した → （判定のやり直し。注文の状態は Q-10） | 要確認（Q-09、Q-10） | 要求資料 §5 |
| 出荷の前に取り消す | 注文が提出された → … → 注文が取り消された → 在庫の引当が解除された（引当があるとき）→ 与信の額が戻された | 仮説 | 要求資料 §6 |
