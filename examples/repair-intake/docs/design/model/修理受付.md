# 修理受付 の論理モデル

既存のコードのうち、資料にある範囲だけを書いた（仮説）。資料にあるのは、テーブルの定義と、受付のコードの検査一つである。

## 集約

| 識別子 | 内容 | 合意状態 |
| --- | --- | --- |
| AGG-REPAIR-01 | 修理依頼（repair_requests の 1 行）。見積だけの依頼と、修理を依頼する依頼の両方を、種別の印で一つにまとめている | 仮説 |

AGG-REPAIR-01 の属性（空を許す属性は、そのとおり書く）

| 属性 | 論理型 | 空を許すか |
| --- | --- | --- |
| 修理依頼の識別子 | 識別子 | 許さない |
| 依頼の種別 | 列挙（VO-REPAIR-01） | 許さない |
| お客様 | 参照 | 許さない |
| 製品の型番 | テキスト | 許さない |
| 症状 | テキスト | 許さない |
| 返送先の住所 | テキスト | 許す |

| 削除の印 | 真偽 | 許さない（既定は「いいえ」） |
