# 用語集

状態の意味は `lifecycles.md`、事実の意味は `facts.md`、業務の対象が何から成るかは `things.md` を引く。ここには名前の区別だけを書く。

## 誤解が実装やテストに響く言葉

| 用語 | 意味 | 合意状態 | 出所 |
| --- | --- | --- | --- |
| 修理依頼書（依頼書） | お客様が、店頭か郵送で出す用紙。「見積だけ」か「修理を依頼」かの印を付ける | 仮説 | 要求資料（抜粋）、修理依頼書の様式 |
| 見積の依頼 | 「見積だけ」に印が付いた依頼書で受け付けるもの。症状を見て見積の金額を連絡するだけで、修理はしない（RULE-REPAIR-01）。別の対象にするかは Q-36 | 要確認（Q-36） | 要求資料（抜粋） |
| 修理の依頼 | 「修理を依頼」に印が付いた依頼書で受け付けるもの。修理して返送し、代金を請求する（RULE-REPAIR-02、RULE-REPAIR-03） | 要確認（Q-36） | 要求資料（抜粋） |
| 見積の金額 | 症状を見て決め、お客様に連絡する金額。依頼書の欄は修理担当者が書く。修理の代金との関係は Q-07 | 要確認（Q-07） | 要求資料（抜粋）、修理依頼書の様式 |
| 修理の代金 | 「修理を依頼」のときに、お客様に請求する代金。見積の金額との関係は Q-07 | 要確認（Q-07） | 要求資料（抜粋） |
| 返送先の住所 | 修理した製品を返送する先。依頼書に書かれた住所（RULE-REPAIR-04）。お客様の登録の住所との関係は Q-09 | 要確認（Q-09） | 要求資料（抜粋）、修理依頼書の様式 |
| お客様の登録 | お客様のお名前、住所、電話番号を、受付担当者が記録したもの（RULE-REPAIR-06） | 仮説 | 要求資料（抜粋） |
| 受付日 | 依頼書を受け付けた日。依頼書の欄は受付担当者が書く。郵送のときの日は Q-22 | 要確認（Q-22） | 修理依頼書の様式 |

## コンテキストごとに意味が違う言葉

コンテキストが一つなので、いまはない。

## 単独で使わない言葉

| 用語 | 使い方 | 合意状態 | 出所 |
| --- | --- | --- | --- |
| 依頼 | 「見積の依頼」「修理の依頼」と呼ぶ。「依頼」だけでは、どちらか分からない | 仮説 | 要求資料（抜粋） |
| 住所 | 「お客様の登録の住所」「返送先の住所」のどちらかで呼ぶ。同じものかは Q-09 | 要確認（Q-09） | 要求資料（抜粋）、修理依頼書の様式 |
| 完了 | 「修理が完了した」と呼ぶ | 仮説 | 要求資料（抜粋） |
