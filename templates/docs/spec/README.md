# 仕様（外部設計）

<!-- 外から何ができ、どう見えるか。外部の振る舞いを合意したときに更新する。業務ルールの本文、ユースケースの中の業務上の条件分岐と計算式は含めない。 -->

- ユースケース（UC-）：業務ルール、判定、操作を識別子で引く。
- 画面（SCR-）。
- 外部 API の振る舞い。
- 画面だけが持ち、業務ルールとして合意していない決まりは、ユースケースの中に「画面だけの決まり」として隔離し、Q- を引く。合意したら domain/rules.md に移す。
- 読み取りモデル（照会や統計が返す応答の形）も、ここに置く。
- 画面のワイヤーフレーム（画像）は、例外として置いてよい。項目と操作の正本はユースケースで、ワイヤーフレームは配置だけを持つ。
